# TASK-INDEX (Global) - Mẫu Chuẩn

Sử dụng cho file: docs/tasks/TASK-INDEX.md

## Quy tắc đồng bộ

- Global index chỉ theo dõi theo sprint, không liệt kê task chi tiết.
- Task chi tiết được quản lý trong từng sprint index.
- Sprint ID theo format: SPRINT-<NN>.
- File index sprint theo format: docs/tasks/sprints/SPRINT-<NN>/TASK-INDEX.md.
